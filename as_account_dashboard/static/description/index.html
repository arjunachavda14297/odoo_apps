Why AS Accounting Dashboard?

The standard accounting dashboard is a set of journal cards. This module answers the questions people ask every morning: How are we doing? What is overdue? Where is the money?

 
The dashboard adds one clear “My Dashboard” menu as the first entry of the Accounting app, so it opens by default. Every number comes straight from posted accounting data, is converted to the current company currency, and is limited by your own access rights — nothing is read with elevated permissions. Every KPI, bar and list row is clickable and opens the matching records, so the dashboard is a starting point for action, not just a report.

Frequently asked questions

 
Does it need Odoo Enterprise?
Yes. The module depends on the Enterprise Accounting app (account_accountant) and adds its menu inside that app.
Why can some users not see Cash & Bank?
Bank balances are the most sensitive figure on the dashboard, so the card, the journal list and the trend popup are limited to the Adviser / Manager group.
In which currency are the amounts shown?
In the currency of the current company. Amounts from other companies are converted automatically, and a notice appears when several currencies are involved.
Can I change what a user sees?
Yes. Dashboard visibility follows the standard Odoo accounting groups, so changing a user’s accounting access right changes their view.
